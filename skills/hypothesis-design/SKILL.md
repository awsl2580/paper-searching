## 什么时候用
文献综述已经给出共识与空白，下一步要"提出一个可以被验证的说法"时。

## 一条好假设的四个条件
1. **有依据**：必须能指向给定文献里的某几条（共识或空白），写清 `basis: [序号]`。
2. **可证伪**：必须写出一条"如果观测到 X，则本假设被否定"的判据。
   写不出否定判据的，是愿景不是假设。
3. **变量明确**：自变量（操纵什么）、因变量（测什么）、控制变量（固定什么）
   三者都要点名，不要出现"环境因素"这种笼统词。
4. **可执行**：在现有数据/工具条件下能做完，至少能做完第一步。

## 步骤
1. 从 `gaps` 里挑一个最具体的空白（"缺少 X 在 Y 条件下的 Z 研究"）。
2. 写假设陈述：`在 <条件> 下，<自变量> 的 <变化> 会使 <因变量> 出现 <方向> 的变化，
   因为 <机理>`。机理部分如果只是猜测，要标注"（推测）"。
3. 给对照：处理组 / 对照组 / 基线，各自怎么构造。
4. 给判据：主指标、阈值、显著性水平（默认 α=0.05）、样本量（用 `design_power` 估）。
   多做一次 `design_power` 检查："我打算做的样本量，能不能支撑这个效应量"——
   跑不动的实验不如不做。
5. 给预期：如果假设成立 / 不成立，分别应该看到什么。**两种都要写**，
   只写成立的那种说明没有认真考虑反例。

## 注意
- 不要提出需要新仪器、新数据集才能验证的假设（这个智能体做不了）。
- 不要用"显著提升"这种量化不了的说法，改成可测的指标名。
- 假设数量控制在 1-3 条，每条独立可测；互相依赖的写成一条。

## 验收
- 每条假设都有 basis / 变量 / 对照 / 判据 / 预期结果；
- 至少一条假设的判据里出现了具体统计量（t、F、r、峰位、分子描述符等）；
- 明确写出本轮的迭代条件："若验证不通过，下一轮调整什么"。
