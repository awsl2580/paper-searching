## 什么时候用
用户要"写一篇综述 / 做文献调研 / 梳理某个方向的研究现状"时。

## 步骤
1. **拆问题**：把研究目标拆成 2-4 个可检索子问题（对象 / 方法 / 场景 / 指标）。
   例："图神经网络在遥感图像语义分割中的应用" →
   `图神经网络 遥感图像 语义分割` / `graph neural network remote sensing segmentation` /
   `高光谱 分类 深度学习`。
2. **定范围**：中文综述用 `source=cn`，国际进展用 `source=en`，全景用 `all`。
   中英文各检索一次再合并，比只查一种语言覆盖更全（中文核心期刊与英文期刊
   重叠度其实很低）。
3. **筛证据**：优先保留带 DOI、有全文直链、近 5 年、被引与相关度都靠前的条目。
   相关度低于 40 的只在"确实需要覆盖早期工作"时才保留，并在综述里标明。
4. **分级**：把文献分成「奠基工作 / 主流方法 / 新近改进 / 综述与展望」四层，
   每层至少在正文里点到一篇。**没有证据的层次就明说没有**，不要用"大量研究表明"
   这种无指的表述。
5. **对齐**：每条论断后面用 `[序号]` 指向给定文献列表，序号必须真实存在。

## 注意
- 同一个观点被 3 篇以上独立文献支持才写"共识"；只有 1 篇时写"有研究认为"。
- 中英文混检时，中文文献的摘要常缺失，不要据此判它"没有方法描述"。
- 不要把检索式里的关键词当成结论，也不要把标题当摘要来引用。

## 验收
- 综述每一节都有引用编号；编号能对上文献表；
- 明确指出至少 1 个研究空白，且该空白能从给定文献的缺失推出来；
- 检索式、范围、命中数、过滤数都记录在报告里，可重复执行。
